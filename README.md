## 🧠 What is CyberShield AI?

> **CyberShield AI** is a research-grade, fully autonomous cyber threat detection and response system built on top of **Deep Learning**, **Autoencoder-based Anomaly Detection**, and a **Reinforcement Learning (PPO) agent** that suggests real-time mitigation actions — all visualized through an interactive **Streamlit Dashboard**.

This project simulates a lightweight **SOC (Security Operations Center)** pipeline — from raw network traffic analysis to automated threat response — using the **NSL-KDD** benchmark dataset.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 🔍 **Anomaly Detection** | Autoencoder reconstructs normal traffic; deviations flagged as threats |
| 🎯 **Attack Classification** | Deep Neural Network classifies: DoS, Probe, R2L, U2R, Normal |
| 🤖 **RL Response Engine** | PPO agent learns optimal mitigation: Allow → Monitor → Block → Isolate |
| 📊 **Live Dashboard** | Streamlit-powered real-time threat visualization |
| ☁️ **Colab Native** | Runs entirely on Google Colab (GPU-accelerated) |
| 💾 **Drive Backup** | Auto-saves models and data to Google Drive |
