# AI Educational Platform

An AI-powered educational mobile app for final-year CS/IT students' placement preparation.

## Overview

This platform provides company-specific quizzes, adaptive learning paths, interview preparation, blockchain certificates, plagiarism detection, and analytics dashboard to help students prepare for placements.

## Tech Stack

- **Frontend:** Flutter (Mobile App)
- **Backend:** FastAPI (Python)
- **Cloud:** Google Cloud Run
- **Database/Auth:** Firebase
- **AI:** TensorFlow/PyTorch
- **Coding API:** Judge0
- **Notifications:** Twilio/SendGrid
- **Infrastructure:** Docker, Terraform, GitHub Actions

## Features

- Company-specific quizzes and assessments
- Adaptive learning algorithms
- Interview preparation modules
- Blockchain-based certificates
- Plagiarism detection
- Analytics dashboard
- Real-time notifications

## Getting Started

1. Clone the repository
2. Set up the backend (see backend/README.md)
3. Set up the frontend (see frontend/README.md)
4. Configure cloud services (see infrastructure/README.md)
5. Run locally with Docker Compose
